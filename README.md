# menghuainanfang.github.io

祁清玄的个人主页，使用原生 HTML 与 CSS 构建，并通过 GitHub Pages 发布。

## 页面内容

- 个人简介与趣味奖项
- 当前主要项目
- GitHub 与 Bilibili 联系入口

## 本地预览

直接打开 `index.html` 即可查看；也可以使用任意静态文件服务器在本地预览。

## 发布方式

仓库的 `.github/workflows/deploy.yml` 会在 `main` 分支更新后自动部署。GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 应设置为 **GitHub Actions**。
